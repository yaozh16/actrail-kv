# 运行约束

## Receiver

- Receiver 等待后端保存整条采集记录后返回 HTTP `202`。
- 非法 JSON 或 JSON non-object body 返回 HTTP `400`；请求体超过限制返回 `413`。
- 单文件 NDJSON 模式在追加失败时回滚到上一个完整记录边界，并停止后续写入。托管 NDJSON 使用目录级写入锁，轮转与有界读取由后端协调。
- SQLite 通过事务提交写入并提供并发读快照。Unix 部署的采集文件仅属主可读写。
- 默认仅监听 `127.0.0.1`。跨主机接入必须由内网反向代理提供 TLS、客户端认证、访问控制和超时，再显式配置监听地址。

## Analyzer、Export 与 Report

- Analyzer、Export 与 Report 写入同目录临时文件，成功后原子发布最终产物。
- 输入与输出不得是同一文件，也不得指向同一硬链接；失败时不会覆写输入或留下伪完整结果。
- 超限、坏行及未知请求结构会记录为 skipped 原因；不得截断请求后产出高置信 defect。
- report 不访问网络、不重新运行算法；HTML 证据必须 HTML escape，Markdown 必须按 GFM 安全转义。

## 数据边界

完整请求、导出语料和诊断证据可能包含敏感数据。采集存储、导出、`analysis.json` 和静态报告必须遵守部署环境的数据分级、访问控制、保留期限和销毁规则。结构诊断基于上游采集的请求与可用的缓存数据。
