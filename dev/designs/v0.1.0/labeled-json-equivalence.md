# 带标签 JSON 等价表示设计

## 解析

`representation.rs` 的 `loose_json(text)`：

1. 先整体 `serde_json::from_str`；成功则标签为空；
2. 失败则找到第一个 `{` 或 `[`，把前部作为标签、后部作为 JSON 再解析；
3. 全部变体都必须解析成功，且标签集合只有一种、JSON 值严格相等、原始文本存在差异，才附加等价事实。

## 边界

- 前导标签不同（如 `Config A:` vs `Config B:`）不判等价；
- 数组顺序变化/值变化保持负例。
