# 采集存储后端

## 目标

- Receiver、Analyzer 和采集记录导出使用共享的 `CaptureStore`。工厂根据配置构造 SQLite 或 NDJSON 后端，支持按角色打开。
- 支持按 `session_key` 等值、按 UTC 采集时间区间 `[from, until)` 筛选，组合条件取交集。读取使用有限记录流，可提前结束。
- 两种后端均支持显式启用的按采集时间清理，默认保留全部记录。保留策略由后端执行。
- 托管 NDJSON 写入按时间窗口和文件大小分片。调用方通过同一条记录流读取，后端处理文件切换、分片遍历和回收。
- 原有 Receiver `--output` 单文件入口和 Analyzer `--input` 兼容入口保留。托管后端由 `--storage-config` 选择。采集记录通过独立命令导出为 NDJSON。
- PostgreSQL 通过同一接口扩展，当前实现范围为 SQLite 和 NDJSON。

## 验收

- 两个后端均可在 Receiver 正常采集时被只读打开，Analyzer 与导出可使用相同的 session 和时间筛选。
- NDJSON 触发时间与大小轮转后，流式读取覆盖各分片；回收只处理符合到期条件的分片。
- SQLite 使用索引查询，按批清理到期记录。配置保留期后，无新流量时仍执行周期清理。
- Git 忽略本地数据库、托管分片和文档示例中的默认运行产物。示例和测试语料可正常纳入版本控制。
- 旧命令和历史 NDJSON 分析兼容性通过既有验证。
