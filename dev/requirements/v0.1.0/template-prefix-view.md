# 每模板前缀视图需求

## 背景

`analysis.json` 的模板字段是摘录型的（稳定片段、槽位摘要），足以定位问题，
但不足以在报告里逐层展开"稳定片段 → 变体 → 之后的稳定片段"这条链。
使用者需要能看到分叉发生在哪个字节区间、每个变体有多少成员、以及该片段关联了哪个缺陷。

## 目标

1. analyzer 为每个模板输出 `templates[].prefix_view`：
   节点类型（`stable` / `dynamic`）、来源（JSONPath / role / 投影单元 / 字节区间）、
   字节数、支持数与支持率、有界摘录、在该片段仍存活的成员、稳定节点的内容样本、
   对齐序列层与内部字节层的子节点、变体（摘录 + 出现次数）、关联缺陷 ID。
2. 输出体积受两个参数控制：`prefix_view_max_nodes`（默认 5000，`0` 关闭输出）、
   `prefix_view_excerpt_bytes`（默认 96）；超过节点上限时截断并置 `truncated = true`。
3. report 渲染「模板前缀树」区块：复用分布（稳定 / 变体区占比）、成员衰减曲线、
   结构片段列表（行内只保留类型、摘要、字节数、支持度）与展开后的字段明细、变体、缺陷锚点。

## 验收

- 具备 `P1 → X → P2` 结构的语料能产出稳定链与非空变体节点；
- 节点数超限时视图被截断且 `truncated = true`，不静默丢字段；
- `prefix_view_max_nodes = 0` 时不输出该字段；
- 旧版 `analysis.json`（无 `prefix_view`）仍可解析，报告不渲染该区块。
