# 会话证据展示重构需求

## 背景

会话证据此前按"一个会话一个区块"渲染，每个区块里再把来源、字节区间、支持度、缺陷 ID
堆在一行。会话一多（真实语料常见几十个），报告又长又难读，
使用者很难从中看出"哪个会话值得关注、哪一轮开始掉"。

本需求只改报告展示，`analysis.json` 的 `session_reports` 契约不变。

## 目标

1. 整段合并为一个区块：先给概览数字（会话数、请求数、复用前缀占比、存在前缀收缩的会话数、可恢复稳定字节），
   再给"需要关注"的会话表（存在非追加事件或前缀收缩，按复用率升序），其余会话按数量折叠或直接铺开。
2. 会话名省略所有会话共有的前缀；尾部不足以辨识时回退显示原名尾部。
3. 事件类型用中文标签（追加 / 分叉 / 重排 / 重置），每行给出复用率与**逐轮**复用率走势。
4. 请求 ID、重算字节、块结构等明细收进行内折叠表，默认收起。

## 验收

- 43 个会话的语料不再产生 43 个区块；
- 全部为追加式增长时给出明确提示，而不是空白；
- 多轮会话能看出逐轮复用率的升降，而不是只显示一个平均值；
- 展示层变更不影响 `analysis.json` 字段与既有校验。
