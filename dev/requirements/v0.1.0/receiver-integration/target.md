# Receiver 接入文档

> 0.2.0 变更：HTTP 作为唯一接入形态的约定由 HTTP 与 SDK 双通道取代，原 HTTP 协议继续有效。见[决策 D04 与替代索引](../../v0.2.0/decisions.md)及[公共采集服务设计](../../../../docs/architectures/receiver/index.md)。

- `actrail-kv` 定义统一的 HTTP 接收协议，并记录自身命令的部署、分析和报告流程。
- 观测组件、代理网关与其他供给方各自适配接收协议。供给方的私有配置和启动方式由供给方文档维护。
- 通用部署指南沿用原有文档路径。[接收协议](../../../../docs/reference/receiver/input.md)作为上报字段的规范入口。
- 公开文档索引链接到随项目分发的文件。
