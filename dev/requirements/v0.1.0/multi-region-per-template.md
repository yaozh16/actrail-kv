# 同一模板多 Region 需求

## 背景

`diagnose_template` 目前每个模板只报告最早一个 P1/X/P2；同一模板若还有第二个“动态槽→稳定尾”，其优化机会不会输出。

## 目标

在同一模板内迭代定位多个失配 region，每个 region 生成一个独立 defect；跳过已被前一个 region 覆盖的区域。

## 验收

- 同一模板两个动态槽、各自后接稳定内容时，产出 ≥2 个 defect；
- defect 的 P2 摘录互不相同（定位不同 region）；
- 既有输入顺序/成员顺序稳定性要求保持。
